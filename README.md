# بصمة أساس العارض

نظام حضور وانصراف ببصمة الوجه والإصبع، يعمل كتطبيق على الجوال، والبيانات محفوظة أونلاين على Firebase.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة التطبيق |
| `app.js` | منطق التطبيق والاتصال بـ Firebase |
| `config.js` | إعدادات مشروع Firebase ورقم المالك |
| `firestore.rules` | قواعد الحماية، تُلصق في Firebase وليس لها دور على GitHub |
| `manifest.json` و`sw.js` وصور `logo-*.png` | التثبيت على الجوال والعمل بدون إنترنت |

## الإعداد مرة واحدة

1. **قواعد الحماية:** في Firebase ادخل **Firestore**، ثم تبويب **Rules**. امسح الموجود، والصق محتوى `firestore.rules` كله، ودوس **Publish**.
2. **الرفع:** ارفع كل الملفات على GitHub في أول الـ Repository، من غير فولدرات.

## الاستخدام

- **المالك:** يدخل بالإيميل وكلمة السر. من لوحته يضيف الموظفين، ويحدد موقع العمل، ويفعّل الإشعارات.
- **الموظف:** يدخل باسم المستخدم (حروف عربي أو إنجليزي وأرقام) وكلمة السر المؤقتة، ويُطلب منه تغييرها. أول بصمة إصبع تربط جواله بحسابه.

## الحماية

- الوقت يُؤخذ من سيرفر Firebase بتوقيت الرياض. تغيير ساعة الجوال لا يفتح التسجيل.
- كل بصمة تتسجّل مرة واحدة في اليوم، ولا يمكن تعديلها أو مسحها إلا من المالك.
- الموظف يرى سجله فقط، والمالك يرى الجميع.

## التحديث

عند رفع نسخة جديدة، غيّر رقم `CACHE` في `sw.js`، مثلاً `v4`.
