# بصمة أساس العارض

نظام حضور وانصراف ببصمة الوجه والإصبع، يعمل كتطبيق على الجوال (PWA).

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كامل |
| `manifest.json` | اسم التطبيق وأيقونته عند التثبيت |
| `sw.js` | تشغيل التطبيق بدون إنترنت |
| `icons/` | أيقونات التطبيق |

## الرفع على GitHub Pages

1. ادخل github.com واعمل Repository جديد باسم `asas-basma`، واختار **Public**.
2. دوس **Add file** ثم **Upload files**، واسحب كل الملفات ومعاها فولدر `icons` كما هو.
3. دوس **Commit changes**.
4. ادخل **Settings** ثم **Pages**.
5. من **Branch** اختار `main` والفولدر `/ (root)`، ودوس **Save**.
6. بعد دقيقة أو اتنين يظهر الرابط بالشكل ده:
   `https://اسم-حسابك.github.io/asas-basma/`

## التثبيت على الجوال

**آيفون:** افتح الرابط من Safari، ثم زر المشاركة، ثم **إضافة إلى الشاشة الرئيسية**.

**أندرويد:** افتح الرابط من Chrome، ثم **تثبيت التطبيق**. لو ما ظهرش، القائمة ⋮ ثم **إضافة إلى الشاشة الرئيسية**.

## ملاحظات

- **بصمة الإصبع:** على الرابط الحقيقي بتستخدم حساس الجوال أو Face ID. أول مرة يربط الموظف بصمته بالجهاز، وبعد كده كل تسجيل بيتطابق عليها.
- **الحفظ:** التسجيلات محفوظة على نفس الجهاز. علشان المالك يشوف بصمات كل الموظفين من جواله، ويوصل الإشعارات فعلاً، المرحلة الجاية ربط Firebase.
- **التحديث:** لما ترفع نسخة جديدة من `index.html`، غيّر رقم `CACHE` في `sw.js` (مثلاً `v2`) علشان الأجهزة تحمّل النسخة الجديدة.
